# 篮球战术板 Basketball Tactics Board

一个基于 Web 的篮球战术板应用，用于绘制和演示篮球战术。

## 技术栈

- React 19 + TypeScript
- Vite 7
- Tailwind CSS + shadcn/ui（Radix UI）
- React Router

## 本地运行

```bash
cd app
npm install
npm run dev
```

## 构建

```bash
cd app
npm run build
```

## 目录结构

```
app/               应用源码
├── src/           页面、组件与逻辑
├── index.html     入口 HTML
└── vite.config.ts Vite 配置
```
